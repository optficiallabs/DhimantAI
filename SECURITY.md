# Security Policy

Security and privacy are core requirements of DhimantAI.

## Reporting a Vulnerability

Please do not report sensitive security issues through public GitHub Issues.

Report privately to `contact@optficial.ai` with:
- affected component
- clear description
- steps to reproduce
- possible impact
- suggested mitigation, if known

Do not include real student data, production credentials, private institution information, or restricted examination content.

## Responsible Disclosure

Please avoid unauthorised testing, service disruption, privacy violations, social engineering, or attempts to access real institution systems.

## Public Repository Rules

Do not commit:
- personally identifiable student information
- confidential institution records
- restricted answer keys or examination material
- API keys, passwords, private keys, or tokens
- production logs containing sensitive information
- restricted third-party content

Use synthetic or otherwise public-safe data for examples and tests.
