# DhimantAI v0.3.0 — Integrated Benchmark, Reporting and Regression Release

## Overview

DhimantAI v0.3.0 turns the project’s initial security reference components into a more complete, measurable evaluation workflow. This release adds a working command-line interface, integrated benchmark evaluation across multiple defensive modules, machine-readable and Markdown reporting, configurable quality gates, and baseline regression tracking.

## Highlights

- working `dhimantai` CLI
- integrated evaluation for content security, assessment integrity, access control, privacy redaction, and workflow-policy cases
- role/action/scope access decisions with fail-closed handling for unknown roles and unsupported scopes
- structured evaluator traces and decision-count metrics
- JSON and Markdown benchmark reports
- expected-vs-actual decision matrix
- failed-case diagnostics
- benchmark report artifacts generated by GitHub Actions
- configurable overall and per-category quality thresholds
- baseline comparison and regression tracking
- detection of newly failing cases, missing baseline cases, changed decisions, and category-level regressions
- preserved backward compatibility for existing `authorise()` behaviour

## Command-Line Examples

Validate learning content:

```bash
dhimantai validate-content examples/sample_learning_content.json
```

Evaluate access:

```bash
dhimantai check-access student view_own_progress --scope self
```

Run integrated benchmark evaluation:

```bash
dhimantai run-integrated-benchmark benchmarks/education_cybersecurity_cases.jsonl
```

Generate benchmark reports:

```bash
dhimantai generate-benchmark-report benchmarks/education_cybersecurity_cases.jsonl --output-dir reports
```

## Continuous Integration

The v0.3.0 release candidate is validated by:

- Tests
- Dependency Review
- Release Readiness
- Benchmark Report
- Benchmark Thresholds
- Benchmark Regression

## Benchmark Quality Policy

The benchmark gate enforces configured overall and category-level minimums. The regression gate separately compares the current evaluation against a reviewed baseline so quality cannot silently decrease even when an absolute threshold still passes.

## Data Safety

All repository examples, benchmark cases, and public reports are synthetic or otherwise public-safe. The repository must not contain identifiable student information, confidential institution records, restricted examination material, credentials, production secrets, or proprietary third-party material without permission.

## Compatibility

Python 3.10 or newer is required.
