# Release Readiness

Before a DhimantAI release, maintainers should confirm:

- all automated tests pass
- no real student or confidential institution data is present
- security-sensitive changes have been reviewed
- assessment-integrity rules behave as expected
- role and permission changes are documented
- benchmark examples remain synthetic or public-safe
- dependency changes are reviewed
- README and documentation match the current code
- release notes describe important changes and limitations

A release should be held if any high-risk privacy, security, or assessment-integrity issue remains unresolved.
