# DhimantAI v0.3.0 Feature Foundation

This development milestone introduces working command-line utilities, richer access-control evaluation, benchmark execution, and reproducible benchmark metrics.

## CLI commands

- `dhimantai validate-content <path>` scans public-safe learning material with the reference content-security rules.
- `dhimantai check-access <role> <action> --scope <scope>` evaluates role, permission and scope boundaries.
- `dhimantai run-benchmark <path>` loads JSONL benchmark cases, executes an evaluator and reports overall/per-category metrics.

## Access-control changes

The reference access-control layer now evaluates both actions and scopes. Unknown roles, unknown permissions and unsupported scopes fail closed. High-impact permitted actions are returned with a `review` decision so production deployments can attach additional approval controls.

## Benchmark metrics

The benchmark runner reports:

- total cases
- correct cases
- incorrect cases
- overall accuracy
- per-category totals
- per-category correct counts
- per-category accuracy

The included reference evaluator mirrors each case's expected decision. Its purpose is to validate benchmark loading, execution, reporting and CI integration. It is not presented as a production security classifier.

## Data safety

Only synthetic, independently created, licensed or otherwise public-safe material should be used with repository examples and benchmark fixtures. Do not add identifiable student information, confidential institution records, credentials, restricted examination material, production secrets or proprietary third-party data without permission.
