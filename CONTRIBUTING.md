# Contributing to DhimantAI

Thank you for contributing to DhimantAI.

## Ways to Contribute

- report bugs and workflow issues
- improve documentation
- add tests
- improve access-control and content-validation utilities
- add synthetic benchmark cases
- improve assessment-integrity checks
- improve developer tooling and automation

## Contribution Process

1. Check existing Issues and Pull Requests.
2. Open an Issue before starting a major change.
3. Create a focused branch.
4. Make the change and add tests where practical.
5. Update documentation when behaviour changes.
6. Open a Pull Request with a clear explanation of the change and testing completed.

## Data and Privacy

Do not commit identifiable student information, confidential institution data, restricted exam material, credentials, production secrets, or unlicensed third-party content.

Use synthetic, public-safe, or appropriately licensed examples.

## Security

Do not report sensitive vulnerabilities in public Issues. Follow `SECURITY.md`.

## Code Quality

Contributions should be readable, testable, documented, and limited to the stated purpose of the change.
