# DhimantAI v0.1.0 — Initial Open-Source Development Release

## Overview

DhimantAI v0.1.0 establishes the first public open-source foundation for guided learning, education workflow controls, content security, assessment integrity, access control, synthetic benchmarks, and maintainer tooling.

## Included

- expanded project README
- Apache License 2.0
- contribution guidelines
- security policy
- Code of Conduct
- development roadmap
- content-security reference checks
- role-based access-control reference module
- assessment-integrity rules
- privacy-aware logging helper
- synthetic learning example data
- education-security benchmark samples
- automated unit tests with GitHub Actions
- dependency-review workflow
- pull-request template
- bug-report and feature-request templates
- documentation overview
- release-readiness guidance
- Codex CLI maintainer workflow documentation

## Data Safety

This release uses only synthetic or public-safe example material. It must not contain identifiable student data, confidential institution information, restricted examination content, credentials, or production secrets.

## Status

This is an early development release intended for evaluation, testing, contribution, and continued open-source development.
