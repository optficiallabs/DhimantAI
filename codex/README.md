# Codex Maintainer Workflow for DhimantAI

This directory documents how maintainers may use Codex CLI in authorised software-development workflows.

Planned uses include:
- repository understanding
- pull-request review
- issue triage
- test preparation
- secure-code review
- documentation maintenance
- release-readiness checks

Important code, security, and release decisions remain under human maintainer review.

Do not provide Codex with real student information, confidential institution records, restricted examination content, credentials, production secrets, or other material that is not suitable for the configured environment.
